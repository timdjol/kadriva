# Kadriva

The split-arm K suggests a frame cut and a projector beam. The wordmark is stored as vector outlines and does not depend on installed fonts.

## Palette
- Auditorium charcoal: #141111
- Curtain vermilion: #E64B38
- Hover vermilion: #FF715B
- Film ivory: #F4EDE3
- Warm grey: #B9AAA3

## Assets
- kadriva-logo.svg: light lettering for dark surfaces
- kadriva-logo-dark.svg: dark lettering for light surfaces
- kadriva-symbol.svg: standalone symbol
- /favicon.svg: browser icon

## Typography
Kadriva Sans is a customized derivative of Manrope, distributed under the SIL Open Font License (see ../fonts/kadriva/OFL.txt). It retains Latin and Cyrillic coverage, narrows the original proportions, and introduces split-arm K/k/К/к. Four weights: 400, 600, 750, 850. The wordmark uses outlined Kadriva Sans ExtraBold with adjusted spacing. This is a modified open-source typeface, not an entirely original alphabet.

Rebuild with scripts/branding/build-font.py and fonttools[woff]. The source font is retained beside that script.
